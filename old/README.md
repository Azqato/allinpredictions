# Podcast Predictions

Much has been written about how AI might increase misinformation, however I believe it can also improve discourse and accountability via automated research and fact-checking. This project is an experiment in that direction.

This project is a small experiment in that direction. Podcasts are full of forward-looking statements, and with modern tools we can build an end-to-end pipeline that transcribes episodes, extracts predictions, and evaluates whether they ultimately came true using automated web research.

Here we evaluate the All-In Podcast, which offers a large archive of episodes and hosts who frequently make predictions about the future. This underlying code could be forked and modified to evaluate other podcasts with minor modifications.

See [allin-predictions.pages.dev](https://allin-predictions.pages.dev) for the final results, or check out [DEVELOPMENT.md](./DEVELOPMENT.md) to learn more about this repository.
